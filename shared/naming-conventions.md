# Naming Conventions

## Documents

Use lowercase.

Use hyphens.

Example

system-overview.md

module-analysis.md

business-rule-index.md

---

## Modules

Prefer repository names.

Avoid translated names.

---

## Business Rules

BR-001

BR-002

BR-003

---

## APIs

Use

METHOD Path

Example

GET /customers

POST /loan/apply

---

## Database

Keep original table names.

Do not rename columns.

---

## Diagrams

Use stable participant names.

Avoid aliases unless necessary.
