# 命名慣例（Naming Conventions）

## 文件

使用小寫。

使用連字號。

範例

system-overview.md

module-analysis.md

business-rule-index.md

---

## 模組

優先採用程式碼庫中既有的名稱。

避免翻譯過的名稱。

---

## 業務規則

BR-001

BR-002

BR-003

---

## API

使用

METHOD Path

範例

GET /customers

POST /loan/apply

---

## 資料庫

保留原始資料表名稱。

不要重新命名欄位。

---

## 圖表

使用穩定的參與者名稱。

除非必要，避免使用別名。
