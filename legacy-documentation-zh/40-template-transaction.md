## 處理細節

State Method 索引中列出的每個方法各一個子章節。

四項深度要素皆為必要。見 `shared/logic-depth.md`。

### Method: `methodName`

**簽章（Signature）**：`<visibility> <returnType> methodName(<params>)`

**原始碼位置（Source）**：`path/to/Class.java:<startLine>-<endLine>`

**何時被呼叫（Invoked when）**：抵達此方法的狀態值、路由參數或呼叫端

#### 處理流程

1. 它讀取什麼、檢查什麼、呼叫什麼、寫入什麼，或接下來去哪裡。

2. ...

3. ...

#### 虛擬碼

```text
BEGIN methodName
  READ ...
  IF <condition> THEN
    ...
    RETURN <state>
  END IF
  CALL ...
  WRITE ...
  RETURN <state>
END
```
